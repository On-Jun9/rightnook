# 개인정보와 배포 자료

## 앱의 데이터 처리

RightNook에는 분석·광고 SDK, 계정 기능, 자체 네트워크 요청 코드가 없습니다. 선택한 경로와 설정을 RightNook 서버로 전송하지 않습니다. 앱으로 열기를 실행하면 선택한 파일·폴더 URL을 사용자가 지정한 앱에 전달합니다. 이후 처리는 해당 앱에 따릅니다.

전체 설정에는 기능 선택·순서, 등록 앱의 이름·bundle ID·경로, 등록 폴더의 이름·경로·bookmark가 저장됩니다. Finder 확장용 메뉴 파일에는 폴더 bookmark와 실제 폴더 경로를 넣지 않습니다. 등록 앱의 경로는 메뉴 파일에도 포함됩니다. 두 파일은 사용자 홈에 저장하며 파일 권한은 `0600`, 저장 디렉터리는 `0700`으로 생성합니다.

- 전체 설정: `~/Library/Application Support/QuickRight/settings-v1.json`
- 메뉴 파일: `~/Library/Application Support/QuickRight/Menu/menu-v1.json`

경로 복사는 사용자가 명령을 선택했을 때 클립보드에 절대경로를 기록합니다. 진단 옵션은 설정 디렉터리와 활성 기능을 표준 출력으로 표시하므로, 진단 결과를 공유할 때는 개인 경로를 확인해야 합니다. Finder 로그에는 로드·메뉴 종류·기능 개수·오류 상태를 기록하며 선택한 파일 경로는 기록하지 않습니다.

macOS가 파일 접근과 저장창 이력 등을 자체적으로 관리할 수 있습니다. 앱을 제거해도 설정과 생성 파일은 자동 삭제하지 않습니다. 설정을 완전히 지우려면 앱을 종료하고 위 설정 디렉터리를 제거합니다.

## 코드·아이콘·기본 문서

| 자료 | 출처와 처리 |
| --- | --- |
| Swift 코드·빌드 스크립트·설정 UI | 이 프로젝트에서 작성, [MIT](../LICENSE) |
| RightNook 앱 아이콘 | 프로젝트의 SVG와 그리기 스크립트로 생성, MIT |
| UI 기호 | macOS의 시스템 기호 API 사용, 별도 기호 파일·폰트 배포 없음 |
| 등록한 외부 앱 아이콘 | 설치된 앱에서 실행 중 조회, 저장소·배포 ZIP에 포함하지 않음 |
| RTF | 스크립트로 작성한 빈 문서, 폰트 파일 포함 없음 |
| DOCX·XLSX·PPTX | 아래 MIT 프로젝트로 생성한 빈 문서, 원저작권 고지 보존 |

기본 문서의 작성자·최종 수정자·제목·설명은 비우고 생성·수정 시각은 고정합니다. 생성 도구의 기본 썸네일·프린터 설정·사용자 정의 XML은 제거합니다. 매크로·첨부 개체·외부 관계·내장 폰트는 포함하지 않습니다. 테마와 스타일에 나오는 폰트 이름은 폰트 파일을 포함한다는 뜻이 아닙니다.

기본 문서 생성에 사용한 프로젝트와 라이선스 원문은 다음과 같습니다. 앱에 Python 런타임이나 패키지 코드를 넣지 않으며, 고지는 소스와 앱의 `THIRD_PARTY_NOTICES.txt`에 함께 제공합니다.

- [python-docx 1.2.0, MIT](https://github.com/python-openxml/python-docx/blob/v1.2.0/LICENSE)
- [openpyxl 3.1.5, MIT/Expat](https://openpyxl.pages.heptapod.net/openpyxl/)
- [python-pptx 1.0.2, MIT](https://github.com/scanny/python-pptx/blob/v1.0.2/LICENSE)

기능을 검토할 때 참고한 다른 앱의 실행 파일·디컴파일 출력·아이콘·문서·스크린샷은 공개 저장소와 배포 앱에 포함하지 않습니다. RightNook은 해당 앱의 공식 후속판이나 제휴 제품이 아닙니다. 문서의 외부 제품 이름은 호환 대상과 파일 형식을 설명하기 위해 사용합니다.
