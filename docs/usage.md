# RightNook 사용법

## 기능 선택

설정창의 Finder 메뉴·새 파일·앱·폴더 탭에서 편집합니다. 모든 탭의 변경 사항은 **적용**할 때 함께 저장합니다. **되돌리기**를 누르면 마지막 적용 상태로 돌아갑니다. 탭을 옮겨도 초안은 유지됩니다.

목록 왼쪽 손잡이를 드래그해 순서를 바꿉니다. 행의 우클릭 메뉴나 더 보기에서도 위·아래로 이동할 수 있습니다. 기능이나 형식을 끄고 켜도 위치는 유지됩니다. 메뉴 미리보기는 편집 중인 상태이며, 실제 Finder에는 적용한 상태가 표시됩니다.

**기본 항목 선택**은 선택 상태만 바꿉니다. 적용해야 Finder에 반영됩니다. 모든 기능을 끄면 Finder의 RightNook 설정 항목도 사라지므로 앱을 직접 실행해 다시 켭니다.

## 새 파일 만들기

새 파일 탭에서 사용할 형식을 선택합니다. Finder에서 형식을 고른 뒤 저장창의 이름·위치를 확인하고 **만들기**를 누릅니다.

| 형식 | 생성 결과 |
| --- | --- |
| TXT·Markdown | 빈 UTF-8 텍스트 파일 |
| RTF·Word | 빈 문서 |
| Excel | 빈 Sheet1 하나 |
| PowerPoint | 16:9 빈 슬라이드 한 장 |

파일 하나를 선택하면 부모 폴더, 폴더 하나를 선택하면 해당 폴더가 기본 위치입니다. 폴더의 빈 공간에서는 현재 폴더를 사용합니다. 여러 항목 선택에서는 새 파일 만들기를 비활성화합니다.

같은 이름의 파일·폴더·심볼릭 링크가 있으면 다른 이름을 입력하도록 안내합니다. macOS가 먼저 대치를 물을 수 있지만 RightNook은 기존 항목 덮어쓰기를 거부합니다. 취소하면 파일을 생성하지 않습니다.

저장 위치가 없어지거나 쓰기 권한·남은 공간이 부족하면 오류를 표시합니다. 실제 쓰기 단계의 실패 후에는 이름·위치를 다시 고르거나 취소할 수 있습니다.

## 경로 복사와 터미널

경로 복사는 선택한 항목의 절대경로를 클립보드에 넣습니다. 여러 항목은 줄바꿈으로 구분합니다. 폴더 빈 공간에서는 현재 폴더 경로를 복사합니다.

Finder 메뉴 탭의 터미널 행에서 Terminal 또는 iTerm2를 선택합니다. 폴더 선택 시 그 폴더를, 파일 선택 시 부모 폴더를 엽니다. 선택한 앱이 없거나 항목을 여러 개 선택하면 비활성화됩니다.

## 앱으로 열기

앱 탭의 **앱 추가**에서 설치된 `.app`을 선택합니다. 여러 앱을 함께 선택할 수 있습니다. 표시 이름, 사용 여부, 순서와 **파일 / 폴더 / 파일·폴더** 대상을 정한 뒤 전체 기능 스위치를 켜고 적용합니다.

Finder의 **앱으로 열기** 하위 메뉴에서 앱을 고릅니다. 파일과 폴더를 섞어 선택하면 둘 다 허용한 앱만 사용할 수 있습니다. 문서 패키지는 파일로 취급합니다. 선택 항목 일부를 임의로 제외하지 않습니다.

열기 대상은 파일·폴더 구분이며 해당 앱이 지원하는 확장자를 지정하는 설정은 아닙니다. 앱마다 열 수 있는 형식이 다릅니다. macOS 기본 연결은 바꾸지 않습니다.

더 보기의 **앱 다시 선택**은 기존 표시 이름·순서·사용 여부·대상 설정을 유지하면서 앱 경로를 교체합니다. **등록 해제**는 목록에서 제거하며 설치된 앱은 보존합니다. 같은 bundle ID는 중복 등록하지 않습니다. 앱이 이동되면 macOS에 등록된 같은 식별자의 앱을 찾고, 없으면 재선택을 안내합니다.

## 자주 쓰는 폴더

폴더 탭에서 폴더를 등록하고 이름·순서를 정합니다. Finder 메뉴에서 고르면 그 폴더를 Finder로 엽니다. **다시 연결**로 위치를 바꿀 수 있으며 **등록 해제**는 실제 폴더를 삭제하지 않습니다.

## 메뉴가 보이지 않을 때

1. 기능을 켜고 적용했는지 확인합니다. 형식·앱·폴더 목록이 비어 있으면 해당 하위 메뉴는 표시하지 않습니다.
2. 설정창 상단의 확장 연결 상태를 확인합니다. 연결이 필요하면 **Finder 확장 설정 열기**에서 RightNook을 켜고 연결 상태를 새로고침합니다.
3. 일반 로컬 폴더에서 우클릭 메뉴를 닫았다가 다시 엽니다. Finder가 확장 항목을 늦게 추가할 수 있습니다.

앱은 한 위치에 설치하세요. 업데이트할 때 기존 앱을 종료하고 같은 위치의 번들을 교체합니다.

## 끄기와 제거

모든 메뉴를 숨기려면 Finder 메뉴의 더 보기에서 **모두 끄기 → 적용**을 누릅니다. 확장을 중지하려면 **Finder 확장 설정 열기**에서 RightNook을 끕니다. 앱을 제거하려면 종료한 뒤 설치한 `RightNook.app`을 휴지통으로 옮깁니다.

설정은 재설치를 위해 남습니다. 이전 로컬 설치와 호환되도록 다음 경로를 사용합니다.

- 전체 설정: `~/Library/Application Support/QuickRight/settings-v1.json`
- 메뉴 표시 설정: `~/Library/Application Support/QuickRight/Menu/menu-v1.json`

앱을 제거해도 생성한 파일과 등록한 폴더는 삭제되지 않습니다.
