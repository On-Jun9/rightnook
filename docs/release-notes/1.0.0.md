## RightNook v1.0.0

macOS Finder 우클릭 메뉴 확장 앱의 첫 공개 버전입니다.

### 기능

- TXT·Markdown·RTF·Word·Excel·PowerPoint 새 파일 만들기
- 파일·폴더·현재 폴더의 경로 복사
- Terminal 또는 iTerm2에서 선택한 폴더 열기
- 설치된 앱 등록, 파일·폴더 대상 설정과 해당 앱으로 열기
- 자주 쓰는 폴더 등록과 Finder로 열기
- 기능별 사용 여부, 드래그 순서, 개별·그룹 메뉴 표시 설정
- 저장창의 기존 이름 충돌 확인과 덮어쓰기 거부

### 설치

`RightNook-1.0.0.zip`을 내려받아 압축을 풀고 `RightNook.app`을 `~/Applications` 또는 `/Applications`로 옮긴 뒤 실행합니다. 앱은 한 위치에만 설치합니다.

개발자 인증서와 Apple 공증 없이 배포합니다. 첫 실행이 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**에서 해당 앱을 허용할 수 있습니다.

설정창의 **Finder 확장 설정 열기**에서 RightNook을 켭니다. 사용할 기능을 선택하고 **적용**을 누릅니다. 처음 설치하면 모든 기능이 꺼져 있습니다.

### 지원 환경

- Apple Silicon Mac, macOS 14 이상을 대상으로 빌드
- 실제 검증 환경: macOS 26.6.2
- 데스크탑·문서·다운로드 접근 시 macOS 폴더 권한 요청 가능

### 알려진 제한

- Intel Mac, 사이드바 우클릭은 지원하지 않습니다.
- 외장 디스크·NAS·클라우드 전용 항목은 별도 검증이 남아 있습니다.
- 앱의 파일 형식 지원은 선택한 앱에 따릅니다.
- 로컬 서명을 사용하므로 업데이트 후 권한을 다시 물을 수 있습니다.
- 자동 업데이트는 제공하지 않습니다.
